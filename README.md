# Campus Life Super App — MVP
A student dashboard for William Jewell College, with six linked HTML pages.

## Technologies
HTML5, CSS, Bootstrap 5, vanilla JavaScript, localStorage, Open-Meteo API and an OpenStreetMap embed.

## Setup and deployment
Open this folder in VS Code and open index.html using Live Server. Internet access is required for Bootstrap, weather and the map. For GitHub Pages, publish the folder containing index.html (for example, /docs on main).

## Features
Home links to all sections. Calendar and Student Tools allow adding and removing local events and tasks. Academic Resources provides study links. Tutoring filters sample subjects. Student Tools also requests current weather. Campus Map embeds an area map.

## Future improvements
Connect official campus events, add a second direct API integration, verify tutoring availability, improve campus map markers, and test accessibility and responsiveness across devices. No account authentication or shared database is included in this MVP.
